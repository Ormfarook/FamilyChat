# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v54.0.0/ before writing any code.

## Do not upgrade the SDK without checking Expo Go first

This project is pinned to **SDK 54** deliberately. It was downgraded from 56 because the
Expo Go builds in the App Store and Play Store could not load a 56 project, which made it
impossible to test on real phones.

Before bumping the SDK, confirm the current store version of Expo Go supports the target —
or accept that testing moves to an EAS development build.
